🚀 Netlify Deployment Guide

To deploy this app on Netlify with zero cost:

  1. Push this repository to GitHub.
  2. Import to Netlify.
  3. Add environment variables in Netlify site settings:
    • DISCORD_WEBHOOK_URL
    • PING_USER_ID
    • TRACKED_PLAYERS
  4. Netlify will automatically execute the scheduled-pinger function every minute!
